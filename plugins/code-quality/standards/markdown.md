# Markdown — Good Practices

Apply on top of the generic coding standards.

- One `#` (H1) per document; use sequential heading levels (don't skip).
- Fenced code blocks with a language tag for syntax highlighting.
- Descriptive link text (not "here"); `alt` text on images.
- Prefer one-sentence-per-line or reasonable wrapping for clean diffs.
- Use reference-style links for URLs repeated many times.
- Tables for tabular data only; lists for simple enumerations.
- Pick a flavor (CommonMark/GFM) and lint with markdownlint.
